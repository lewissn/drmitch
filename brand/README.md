# Dr Mitch logo files

The symbol is a ring around a dumbbell cross. Every file is an SVG, so it stays sharp at any size, and the lettering is converted to outlines, so it needs no fonts installed. Colours: blue `#2F5A8F`, ink `#17171A`, paper `#F3F1EC`.

| File | Use it for |
| --- | --- |
| `drmitch-symbol.svg` | The symbol on its own: social profile pictures, favicons, stickers, embroidery. |
| `drmitch-symbol-512.png` | The symbol as a PNG, for places that don't accept SVG. |
| `drmitch-logo-compliant.svg` | **Default for anything public**: "Dr Mitch" with "Doctor of Chiropractic" directly beneath. |
| `drmitch-logo.svg` | The full logo with "The Body Mechanic". Hold until it's been checked (see below). |
| `drmitch-logo-reversed.svg` | The full logo in paper colour, for placing on the brand blue or a photo. Same hold. |

## The "Dr" rule

UK advertising rules (CAP/ASA) and the General Chiropractic Council require "Dr" to be followed immediately by "Doctor of Chiropractic" in anything public, including signs and social media. `drmitch-logo.svg` and `drmitch-logo-reversed.svg` show "Dr Mitch" with "The Body Mechanic" instead. Before using them publicly, ask a solicitor or CAP Copy Advice to confirm they're acceptable, and that "The Body Mechanic" doesn't suggest the treatment fixes or repairs the body.
